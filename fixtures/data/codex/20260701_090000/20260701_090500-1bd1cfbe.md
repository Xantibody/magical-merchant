# How this app decides things

## Simple beats configurable

Every setting is a question asked of someone who came here to write. The
default has to be right often enough that the question need not be asked.

## The file is the record

What is on disk is plain Markdown that another tool can read. Anything
the app knows that the file does not is a thing that will be lost.
