# How this app decides things

## Simple beats configurable

Every setting is a question asked of someone who came here to write. The
default has to be right often enough that the question need not be asked.

## The file is the record

What is on disk is plain Markdown that another tool can read. Anything
the app knows that the file does not is a thing that will be lost.

## Lazy by default

The startup path carries the rail, the list and nothing else. The editor
arrives with the first note, diagrams with the first diagram.

## Motion says where, not that

Transform and opacity, one easing, under 350ms. A movement that does not
tell you where something came from is decoration.

## Nothing is deleted without a way back

Delete offers an undo for five seconds; a Codex keeps every version it
was told to keep. The exception is a version you commit by accident,
which the toast lets you take back at once.
