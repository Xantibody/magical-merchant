# The flyout, written up

Grown out of the Scrawl entry from the 3rd, which said only that the
flyout should float rather than push.

What the entry left out: the pane has to be reachable without a pointer,
so the same key that opens it has to pin it. Hover alone strands anyone
on a keyboard.
