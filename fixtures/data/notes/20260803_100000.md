# House rules for this notebook

Kept read-only on purpose: it is looked at, not edited.

1. One record, one place. A thought lives in Scrawl, Note or Codex, never
   in two of them.
2. A note's filename is its name for good. Titles change; the file does
   not.
3. If it needs a version, it is a Codex. If it needs a date, it is a
   Scrawl entry. Everything else is a Note.
